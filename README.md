# Ryan Zhao's Portfolio

A modern, responsive portfolio website built with Next.js, React, and Styled Components.

## Features

- 🎨 Modern, clean design
- 🌙 Dark/Light mode toggle
- 📱 Fully responsive
- ⚡ Fast performance
- 🎯 SEO optimized

## Installation & Set Up

1. Install dependencies

   ```sh
   npm install
   ```

2. Start the development server

   ```sh
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser

## Building and Running for Production

1. Generate a production build

   ```sh
   npm run build
   ```

2. Start the production server

   ```sh
   npm start
   ```

## Technologies Used

- Next.js
- React
- Styled Components
- Tailwind CSS
- Framer Motion
